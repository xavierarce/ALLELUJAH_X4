# Projet de fin de module — Scripting Python / Cybersécurité

## Système de notation

> **Note finale = Code (/10) + Soutenance (/10) = /20**

---

## Note Code — /10
*Identique pour tous les membres du groupe.*

| Critère | Ce qu'on regarde | Points |
|---|---|---|
| **Fonctionnalité & robustesse** | L'extraction fonctionne, gère les erreurs (API down, champ manquant, timeout) | /4 |
| **Qualité du code** | Répartition en fonctions/fichiers (pas de monolithique), lisibilité, usage cohérent du contenu vu en cours | /2,5 |
| **Donnée restituée** | Le fichier de sortie (JSON/CSV) est propre, structuré, exploitable en aval | /2,5 |
| **README / explication de lancement** | L'outil est exécutable depuis toute machine à partir des instructions fournies | /1 |
| **Total** | | **/10** |

---

## Note Soutenance — /10
*Collective, sauf le Q&A et l'expression orale, notés individuellement.*

| Critère | Ce qu'on regarde | Points | Mode |
|---|---|---|---|
| **Cadre du projet** | Présentation du sujet et identification du besoin | /1 | Collectif |
| **Organisation du projet** | Répartition du travail explicitée et cohérente (tout le monde code, chef de projet + exécutants, pair programming…) | /2 | Collectif |
| **Démo** | Le code du projet et sa démonstration | /2 | Collectif |
| **Proposition** | Vision de la solution finale, améliorations possibles identifiées | /1 | Collectif |
| **Q&A** | Réponses aux questions de l'enseignant | /2 | **Individuel** |
| **Expression orale** | Clarté, aisance, capacité à expliquer sans lire un script | /1 | **Individuel** |
| **Répartition du temps de parole** | Équilibre du temps de parole au sein du groupe | /1 | Collectif |
| **Total** | | **/10** | |

---

## Organisation pratique

- Le **code est livré en Séance 9**, ce qui laisse le temps de préparer des
  questions techniques ciblées et adaptées au travail réellement produit par
  chaque groupe, avant la **soutenance en Séance 10**.
- Les **critères collectifs** de la soutenance (cadre, organisation, démo,
  proposition, répartition du temps de parole) sont notés **une seule fois pour
  tout le groupe**. Seuls le **Q&A** et l'**expression orale** sont évalués
  **individuellement**, pour chaque étudiant.
